# CRUDER

**CRUD + -er (행동하는 사람)**

소프트웨어의 가장 기본적이면서도 본질적인 핵심 동작인 **CRUD(Create, Read, Update, Delete)**를 완벽하게 구현하고 다루는 **사람들(CRUD-er)**

*기초를 단단하게, 본질에 충실한 개발을 지향합니다*

*웹 개발의 근간인 데이터 흐름을 능숙하게 제어하고, 실질적인 가치를 만들어내는 개발자로 거듭나겠다는 의지를 담았습니다.*

## 팀원 

- 유도영 (팀장)

- 조규혁 (팀원)

- 변준석 (팀원)

- 김상우 (팀원)

## 규칙 

- 코딩을 1시간 이상 하지 않기 (10분마다 휴식 취하기)

- 5분이상 해서 막히면 팀원이나 강사님에게 도움 요청하기

  - 막혔을때 어떤부분이 막혔는지 자세하게 설명할 것.
